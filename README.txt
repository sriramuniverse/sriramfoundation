Sriram Foundation Website

Files:
- index.html: complete website (HTML, CSS, JavaScript, Bootstrap 5)

How to run:
1. Extract this ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

Internet connection is needed for Bootstrap, Font Awesome, Google Translate, and remote photos.
Volunteer registration is a front-end demonstration and does not store/send submissions. Replace placeholder contact details before publishing.
